# transfer-up-watch

Public dashboard for the **Transfer-Up Board** — the best G5 and FCS college football
players with eligibility remaining, ranked weekly on that week's play, for
transfer-up representation.

Rebuilt every Monday in season and republished to the same URL. The generator,
methodology and decision record live in the private `brain` repo under
`projects/transfer-up-tracker/`.

**Nothing but `index.html` is published.** PFF exports and the season store are
licensed data and never enter this repo.
